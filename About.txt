- PaintScript only for now.

I made a new empty console project, we will make the PaintScript Engine here instead of directly in the VM.

So we are restarting. 

Here is a basic script:

#PaintScript Alpha 0.1
#Sprite Sprite_1

@Start {
	var message:String = "Hello, World!";
	say(AddSmile(message));
}

function AddSmile(test) {
	return test + " :)";
}

This get's compiled to json, then it get's linked, the linker links all the output json together making the final json program that the engine runs. Example final program:
